# 2. 아파트 관리비 자동납부 연결 가능 단지 데이터 조회

## APARTMENT_RP_LIST

이 detail은 문서 안내 RAG가 아니라 실제 연결 가능 단지를 조회하는 MCP
시나리오다. 다음 중 하나가 명확할 때 선택한다.

1. 구체적인 아파트명·단지명 또는 주소와 함께 연결 가능 여부를 묻는다.
2. 연결 가능 단지 목록, 아파트 검색, 지역별 가능 단지 조회를 명시한다.
3. `아파트 자동이체 조회`, `아파트 관리비 자동납부 조회`처럼 신청 방법이 아니라
   실제 단지 데이터 조회를 요청한다. 이때 검색값이 없으면 address는 null이다.
4. 질문 전체가 구체적인 아파트명·단지명 또는 주소만으로 구성되어 있다. 이 경우
   조회 동사가 생략되어도 입력 전체를 address로 추출한다.

### 선택하는 질문

- `래미안 원베일리 관리비 자동납부 가능해?`
  → address=`래미안 원베일리`
- `역삼동에서 연결 가능한 아파트를 찾아줘`
  → address=`역삼동`
- `강남구 관리비 자동납부 가능 단지 목록을 보여줘`
  → address=`강남구`
- `서울시 강남구 테헤란로에서 관리비 자동납부 가능한 단지를 조회해줘`
  → address=`서울시 강남구 테헤란로`
- `수원시 영통동 아파트 자동이체 가능 여부를 조회해줘`
  → address=`수원시 영통동`
- `서울시 강남구 테헤란로`
  → address=`서울시 강남구 테헤란로`
- `수원시 영통동`
  → address=`수원시 영통동`
- `역삼동`
  → address=`역삼동`
- `래미안 원베일리`
  → address=`래미안 원베일리`
- `아파트 자동이체 조회해줘`
  → address=null, MCP를 호출하지 않고 주소 입력 고정안내 반환
- `연결 가능한 아파트 목록을 조회해줘`
  → address=null, MCP를 호출하지 않고 주소 입력 고정안내 반환

### 선택하지 않는 질문

- `아파트 자동납부 신청 방법 및 처리 절차를 알려줘`
- `아파트 관리비 자동납부 해지 방법 알려줘`
- `아파트 관리비 자동납부 가능한 조건이 뭐야?`
- `아파트 관리비 자동납부 제한 기준을 알려줘`

위 질문은 모두 `APARTMENT_MANAGEMENT_FEE_AUTOPAY_GUIDE`다.

### 파라미터

- `address`에는 사용자가 실제로 입력한 아파트명·단지명·읍면동·지역명만 넣는다.
- 아파트명이 없어도 `서울시 강남구 테헤란로`, `수원시 영통동`, `강남구`,
  `역삼동`처럼 시·도·군·구·읍·면·동·로·길이 포함된 전체 또는 부분 주소를
  address로 추출한다.
- 주소가 문장 안에 있으면 조사와 조회 요청 문구를 제외하고 사용자가 입력한
  위치 표현만 추출한다.
- 질문 전체가 주소·아파트명·단지명이라면 별도 요청 문구가 없어도 전체 검색값을
  address로 추출하고 `APARTMENT_RP_LIST`를 선택한다.
- `아파트`, `아파트 관리비`, `자동이체`, `자동납부`, `RP`, `주소`, `지역`은
  단독으로 address가 아니다.
- 실제 단지 조회 목적이 명확하지만 검색값이 없으면 null로 반환한다.
- 질문에 없는 검색값을 임의로 생성하지 않는다.

이 detail은 Python handler에서 먼저 구주소/신주소 선택 action을 요청한다.
address가 JSON null이면 선택 후 `구주소를 입력해 주세요.` 또는
`신주소를 입력해 주세요.`로 일반 채팅창 입력을 안내한다. 문자열 "null"을
검색값으로 생성하지 않는다. 주소가 이미 있으면 선택 후 즉시 조회한다.
`조회된 결과가 없습니다`는 실제 MCP가 무데이터 결과를 반환한 뒤에만 사용한다.
