# 2. 신규 안내 멘트 및 접수 상태 확인

## GREETING_MESSAGE_CONFIRMATION

신규 카드 접수 완료 시 태블릿 화면에 나타나는 안내 멘트를 보지 못했거나,
멘트의 의미와 현재 접수 고객의 실제 신규·기존 상태 또는 실적 반영 상태를
확인하려는 질문이다.

### 선택 범위

- `감사합니다`, `첫신청 감사합니다`, `환영합니다`, `다시 신청해주셔서
  감사합니다`, `과거에 신청하신 정보가 있습니다` 등 접수 완료 멘트의 의미
- 안내 멘트를 보지 못했거나 화면이 바로 넘어간 경우의 접수 상태 확인
- 태블릿 접수 문맥에서 `이 고객 신규야?`, `이 사람 기존 회원으로 나온 거야?`
  같이 실제 신규·기존 여부를 확인하는 질문
- 복합 모집 방식에서 URL 전송 절차가 정규 접수인지 확인하는 질문

### 선택하지 않는 범위

- 가상의 신청자가 충족해야 하는 일반적인 신규 입회 자격과 필요 서류
- 특정 고객의 실적·수수료·폐기·미등록 상세정보

이 detail은 파라미터를 사용하지 않는다. 질문에 없는 안내 문구나 신규·실적
반영 결과를 생성하지 않는다.
