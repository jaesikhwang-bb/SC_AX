# 3. 태블릿 비밀번호 관리

## PASSWORD_CHANGE

- 로그인 가능한 상태에서 비밀번호 변경 방법을 묻는 경우
- 비밀번호 90일 경과 또는 임시비밀번호 변경 안내를 받은 경우

## PASSWORD_RESET

- 비밀번호가 맞지 않아 로그인할 수 없고 초기화를 요청하는 경우
- 비밀번호를 잊어 셀프 초기화 또는 담당 경로 안내가 필요한 경우
- 유치조직별 실제 안내 방식은 애플리케이션이 처리하며 이 분류 단계에서
  유치조직구분코드나 지점 정보를 만들지 않는다.

두 detail 모두 파라미터를 사용하지 않는다. 로그인할 수 있는 상태의 일반 변경은
`PASSWORD_CHANGE`, 로그인할 수 없거나 비밀번호를 잊은 초기화는
`PASSWORD_RESET`으로 구분한다.
