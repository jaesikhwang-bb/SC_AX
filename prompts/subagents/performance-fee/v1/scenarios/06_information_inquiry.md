# 6. 수수료 고정 안내

아래 detail은 MCP 조회 없이 고정답변을 반환한다. parameters는 {}다.
질문 문장을 그대로 일치시키지 말고 문의 목적을 판단한다.

## FEE_DETAIL_GUIDANCE
기타·효율 등 지급 수수료 항목의 뜻, 상세 설명, 금액이 이상하다는 이의 문의.
예: 기타 수수료가 뭐예요? / 효율 수수료가 이상해요.
실제 월별 항목 금액을 요청하는 "이번 달 기타수수료 얼마야?"는 FEE_ITEM_DETAILS다.
상품·모집유형별 공식 수수료율·산정표는 FEE_POLICY 업무와 구분한다.

## FEE_LONG_TERM_HISTORY_GUIDANCE
작년 카드에서 받은 돈, 연간·12개월 수수료 합계·추이 등 장기 내역 문의.
특정 한 달의 수수료 금액 조회는 FEE_ITEM_DETAILS다.

## FEE_PAYMENT_DATE_GUIDANCE
급여·월급·수당·수수료 지급일이나 지급 시기 문의.
예: 급여 날짜가 며칠이죠? / 수당 언제 줘요? / 월급 언제 나와요?
실제 금액 조회와 구분한다.

## FEE_FAX_UNAVAILABLE_GUIDANCE
일반 수수료 내역 팩스 발송 요청. 예: 수수료 팩스 보내주세요.
원천징수 내역의 팩스 전송은 기존 WITHHOLDING_TAX_FAX_SEND를 선택한다.
이력에서 원천징수로 명확히 이어진 보정 질문도 원천징수 팩스 기능을 유지한다.
