# 서브에이전트 선택 규칙

다음 6개 에이전트 중 질문의 핵심 요청을 직접 처리하는 하나만 선택한다.

| agent_code | 핵심 업무 |
|---|---|
| PERFORMANCE_FEE | 로그인한 모집인 본인의 실제 실적·환산점수·지급 수수료·세금·실지급액 조회 |
| FEE_POLICY | 카드 상품·유치조직·복합판매 유형별 수수료율·환산점수·실적 인정 정책과 기준 |
| QUALIFICATION | 개인회원·외국인·미성년자·가족카드의 일반 입회 자격과 증빙서류 기준 |
| RP | 자동납부 등 RP 서비스의 신청·변경·해지 절차와 실제 아파트 연결 가능 단지 조회 |
| PRODUCT_GUIDE | 카드 상품의 혜택·연회비·추천·비교와 상품 자체의 제공 조건 |
| TABLET | 태블릿 화면·오류·접수 절차·안내 멘트·로그인 비밀번호 문제 |

## 판정 순서

1. 질문에서 사용자가 원하는 행위가 실제 개인 데이터 조회인지, 정책·기준 안내인지,
   상품 정보인지, 시스템 조작·장애 해결인지 구분한다.
2. 질문의 대상과 요청 행위를 함께 비교한다. `수수료`, `신규`, `발급`, `RP`,
   `아파트` 같은 단어 하나만으로 선택하지 않는다.
3. 각 에이전트의 선택 조건과 선택하지 않는 조건을 모두 적용한다.
4. 여러 에이전트의 업무가 한 질문에 함께 있어도 마스터는 주된 요청 하나를
   선택한다. 주된 요청을 정할 수 없다는 이유로 질문의 의미를 새로 만들지 않는다.

## 충돌 방지 경계

- 본인이 실제로 받은 금액·점수·건수·내역 조회는 `PERFORMANCE_FEE`, 상품이나
  판매유형별로 얼마를 인정하는지 묻는 기준·비율·반영 조건은 `FEE_POLICY`다.
- `이번 달`, `지난달`, `6월` 같은 조회 기간과 함께 `몇 점`, `올라올 점수`,
  `실적 빠진 것`을 묻는 질문은 본인의 실제 데이터 조회이므로
  `PERFORMANCE_FEE`다. 특정 카드·연결 유형을 판매하거나 연결하면 원칙적으로
  몇 점을 인정하는지 묻는 질문은 `FEE_POLICY`다.
- `전월 실적`이 특정 카드의 할인 혜택을 받기 위한 이용금액 또는 제외 매출을
  뜻하면 `PRODUCT_GUIDE`, 로그인한 모집인의 월별 발급·환산 실적을 뜻하면
  `PERFORMANCE_FEE`다.
- 수수료 명세에 표시된 항목의 의미나 본인 지급내역 관련 FAQ는
  `PERFORMANCE_FEE`가 처리한다. 특정 카드·유치조직·복합판매 유형의 수수료율,
  환산점수 또는 인정 기준은 `FEE_POLICY`다.
- 특정 카드 상품의 혜택·연회비·추천·비교는 `PRODUCT_GUIDE`, 신청자의 연령·
  가족관계·체류자격·소득·서류 등 일반 입회 자격은 `QUALIFICATION`이다.
- 특정 카드가 가족카드 기능을 제공하는지 또는 그 상품의 가족카드 혜택을 묻는
  질문은 `PRODUCT_GUIDE`, 누가 가족카드를 신청할 수 있는지 묻는 질문은
  `QUALIFICATION`이다.
- 특정 고객이 실제 신규·기존 회원인지 확인하거나 태블릿의 신규 안내 멘트·접수
  상태를 묻는 질문은 `TABLET`이다. 일반적인 신규 입회 자격은
  `QUALIFICATION`이다.
- 태블릿으로 접수 중인 카드·해외용·교통 기능을 변경하는 방법은 `TABLET`,
  어떤 카드를 선택할지 또는 상품 혜택을 비교하는 질문은 `PRODUCT_GUIDE`다.
- 자동납부 서비스의 신청·변경·해지·제한 절차는 `RP`, 해당 연결이 몇 점으로
  인정되는지와 반영 기준은 `FEE_POLICY`, 본인의 실제 RP 환산점수·미반영 내역은
  `PERFORMANCE_FEE`다.
- 가족카드·리볼빙·간편결제·하이패스·모니모·쇼핑케어 등을 신청하거나 판매했을
  때 모집인 실적으로 인정되는지, 몇 점인지, 어느 달에 반영되는지를 묻는 질문은
  `FEE_POLICY`다. 서비스 이용·신청 절차나 카드 상품 혜택을 묻는 질문과 구분한다.
- 특정 고객의 자동납부 신청 취소, 사후 신청, 타기관 자동이체 전환, 실제 연결
  상태를 문의해도 업무 대상이 자동납부 서비스이면 `RP`다. 고객이 언급됐다는
  이유만으로 PERFORMANCE_FEE나 QUALIFICATION을 선택하지 않는다.
- 질문 전체가 구체적인 아파트명·단지명 또는 시·도·군·구·읍·면·동·로·길
  형태의 주소만으로 구성되어도 아파트 관리비 연결 가능 단지의 검색값 입력으로
  보고 `RP`를 선택한다. 별도의 조회 동사가 없어도 같은 원칙을 적용한다.
- 예금·보험료·재산·배우자·직업·직장 확인·신용회복·파산·체류기간처럼 신청자의
  조건을 일반 입회 규정에 대입하거나 필요한 증빙서류를 묻는 질문은
  `QUALIFICATION`이다. `아파트 자격`도 아파트 보유·재산을 입회 자격으로
  인정하는지 묻는 의미이면 QUALIFICATION이고, 관리비 자동납부 연결 가능 여부는
  `RP`다.
- 삼성 후불하이패스의 신청·이용 업무 절차는 `RP`, 상품 혜택·연회비·추천은
  `PRODUCT_GUIDE`, 태블릿 접수 중 발생한 오류는 `TABLET`이다.
- 오류 문구에 태블릿이라는 단어가 없어도 접수 화면에서 실명·신분증·계좌·
  대외정보·일련번호·인터페이스·송신·전문·DB·서명·임시저장·심사배분 오류가
  발생했거나 화면에서 카드·로고·추천카드를 바꾸는 방법을 묻는다면 `TABLET`다.
